Before You Start

What this diagnostic does

It doesn't tell you anything new about the Theory of Constraints — it just makes you answer the same four questions the Five Focusing Steps always start with, then plugs your answers into the framework so the output reads like a diagnosis instead of a worksheet. Have rough numbers ready: current WIP, recent throughput, and a sense of where work backs up.
